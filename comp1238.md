
# COMP 1238 - Introduction to Data Management

## Week 1 - History
- Cuneiform was an early writing system that used wedge-shaped marks pressed into clay tablets.
- Early writing was used to keep records of goods and transactions, including barley and beer.

## Week 2 - Bits and Bytes
- Computers use binary (base 2), which consists of 0s and 1s. One byte contains 8 bits.
- Volatile memory (RAM) loses data when power is off, while non-volatile storage (SSD or HDD) retains data.

## Week 3 - Text Structure
- Lines and indentation help organize code and make it easier to read and understand.
- Markup languages such as HTML and Markdown are used to structure and format text.

## Week 4 - Keyboards and Text Editors
- Touch typing and keyboard shortcuts improve efficiency and reduce fatigue when working with text.
- Text editors such as Notepad work with plain text, while word processors such as Microsoft Word provide document formatting features.

## Week 5 - Command Line Interfaces
- A Command Line Interface (CLI) allows users to interact with a computer by typing commands instead of using graphical menus.
- CLI commands such as `ls` and `cd` help users navigate files and directories, while scripts can automate repetitive tasks.
